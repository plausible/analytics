        list_modifiers()

        Lists the modifiers of all subscriptions (read-only), following pagination.

        Each modifier has "modifier_id" (integer), "subscription_id" (integer), "amount" (string, negative for discounts), "currency", "is_recurring" (boolean) and "description".

        The endpoint pages with after: the id of the last modifier of the previous page.

        See POST /2.0/subscription/modifiers in Paddle's Subscription API.

        list_plans()

        Lists every plan of the Classic catalog (read-only), following pagination.

        Each plan has "id" (integer), "name", "billing_type" ("day", "week", "month" or "year"), "billing_period" (integer), "trial_days" (integer) and "initial_price" / "recurring_price" maps of currency code => amount string.

        See POST /2.0/subscription/plans in Paddle's Subscription API.

        check_plan_files(files, prices)

        @spec check_plan_files(map(), map() | {:error, String.t()}) :: [problem()]

        Pure part of plan_files_integrity/1, for testing and for use on data that isn't on disk.

        files maps a file name without extension (for example "plans_v1") to its decoded JSON (a list of plan maps), prices is the decoded plan_prices.json (plan id => price). A value of {:error, message} stands for a file that couldn't be read.

        Checks:

        • :unreadable - a file is missing or isn't valid
        • :generation_mismatch - a plan's generation doesn't match its file
        • :bad_id_format - an id isn't a numeric (Paddle Classic) id
        • :same_monthly_and_yearly_id - a plan uses one id for both intervals
        • :duplicate_id - an id is used more than once
        • :duplicate_plan - two plans in a file share kind and pageview limit
        • :missing_price / :orphan_price / :bad_price - plan_prices.json has to hold a positive price for every plan id, and nothing else

        plan_resolution(opts \\ [])

        @spec plan_resolution(Keyword.t()) :: map()

        Resolves subscriptions to plans exactly like the app does (Plausible.Billing.Plans.get_subscription_plan/1) and summarises the result.

        Options:

        • :scope - :live (default) audits every subscription that could matter for a port: active, past due or paused, plus cancelled ones that are still inside the paid period. :current audits the last subscription of every team, which is the one the app uses to determine a team's plan.
        • :today - the date used for "still inside the paid period" (default: today, UTC).
